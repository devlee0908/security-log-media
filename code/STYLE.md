# security.log 취향·품질 기준 (사용자 피드백 누적 기록)

새 대화든 예약 실행이든 제작 전에 반드시 읽고 따른다. PIPELINE.md 와 충돌하면 이 문서가 우선.

## 브랜드
- 계정 @security.log / 표시명 "Security Log | 매일 보는 보안 뉴스" / 로고 `>_` + SECURITY.LOG
- 카테고리 색: NEWS 그린 #2BFF88, CVE 레드 #FF4D5E, TREND 오렌지 #FF8A3D, TIPS 골드 #FFC83D, WEEKLY 블루 #5AB0FF, WORDS 퍼플 #B48CFF
- 표지 태그는 로그 스타일 `[CAT] YYYY-MM-DD`(NEWS·CVE·WEEKLY) 또는 `[CAT] #00N`(TREND·TIPS·WORDS). 다른 계정(AI Freaks) UI 를 닮으면 안 됨.
- 사용자에게 하는 설명은 항상 한국어.

## 문구
- '가족' 금지. 팔로우 장 문구는 "저장해두고 동료에게 공유해 주세요" 고정.
- 표지 제목 2줄, 한 줄 약 12자. 본문 4줄 이내(약 110자). 제목 줄바꿈 \n, 본문 강조는 [대괄호].
- 그림 속 개수·숫자 = 제목·본문 숫자 (예: "6곳"이면 노드 6개). 사용자가 직접 지적했던 항목.
- 사실은 원문·공식 발표로 교차 확인. 출처 1곳뿐이거나 날짜가 안 맞으면 쓰지 않는다. 추측·과장 금지.
- 캡션: 따옴표 훅 → 짧은 단락 3~4개 → 👉🏻/💾 두 줄 → 해시태그 8~10개 → `security.log · CAT [#00N]`.

## 화면
- 표지: 그날 주제에만 맞는 장면. 이전 표지 장면 재사용 금지(사용자가 바로 알아챔). 제목 위치 태그 top 842px / 제목 top 914px(사용자 확정).
- 본문 장: 위 영상 794px, 제목 80px, 본문 36px(참고 계정 비율). 번호 배지는 반투명 아이폰 글래스.
- 선·점·패킷이 글자 위로 지나가면 안 됨("다 깨진다" 피드백). 화면 밖으로 잘리는 요소 금지.
- 장수는 8~10장으로 충분히(7장은 "너무 짧다" 피드백). 인스타 API 한도 10장.
- **반복 금지가 최우선 불만**: "늘 봐왔던 영상"이 가장 큰 지적. 매 게시물 스토리보드를 새로 짜고, 스타일 3종 이상·옆 장 같은 스타일 금지·도식/HUD 최대 2장(PIPELINE.md 장면 다양성 규칙).
- 좋은 기준 예시: `ref_tips001.jpg` (TIPS #001 패스키 편 — 키네틱 타이포, 픽토그램, 밝은 UI, 아이소메트릭, 브라우저 비교, 큰 숫자 단계, 밝은 픽토그램). 수준은 맞추되 장면을 그대로 재사용하지 말 것.
- 어두운 장과 밝은 장(lightBg, data.light)을 섞어 넘길 때 분위기가 바뀌게.

## 품질 검사 (렌더 후 반드시)
각 장 5초 프레임을 한 장으로 붙여 Read 로 보고 하나라도 걸리면 고친다:
잘림 / 글자 겹침 / 휑한 빈 공간 / 너무 작은 글자 / 최근 게시물과 비슷한 장 / 장면이 주제를 못 전함 / 숫자 불일치 / 오타.

## 진행 방식 (대화형)
주제 후보 2~3개(출처 포함) → 사용자 선택 → 스토리보드(장마다 비유·스타일 한 줄) 확인 → 렌더 → 미리보기 → 수정 → 사용자가 "게시"라고 하면 게시. 게시는 반드시 명시적 승인 후에만.
